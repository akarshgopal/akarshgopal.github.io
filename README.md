# How the World's Electricity Works — interactive explainer

Static site. Open `dist/index.html` directly in a browser (works from file://), or serve it:

    cd dist && python3 -m http.server 8000   # then open http://localhost:8000

Build (pnpm only): `pnpm install && pnpm run build` → bundles `src/` into `dist/` with esbuild.
Screenshots / checks: `pnpm run shots` (Playwright + system Chrome).

- `src/index.html` is generated by concatenating `src/index.part{1,2,3}.html`.
- `src/figs/*.js` — one module per group of figures; `src/lib/` — canvas/UI helpers, market model, LP solver, data (generated by `scripts/make_data.py`).
- Layout audit: `node scripts/audit.mjs [widths] [figs] [--stress]` (default widths 1280,1024,768,390). Records every canvas label's
  bounding box and reports clipped text, overlapping labels, DOM overflow, bad aspect ratios and the floating play button covering
  a figure. `--stress` also drives every slider to its min/max and clicks every button. Output: `screenshots/audit*.txt`.
- v2 added §12 (renewables, nuclear, learning: `learning`, `foak`, `cleanGrid`) and §14 (the economic lever: `energyShare`, `unlock`),
  in `src/figs/clean.js` and `src/figs/economy.js`; data in `src/lib/data2.js`.

- **Build:** `pnpm run build` → `dist/`. Two bundles: `app.js` (main essay, includes three.js) and `series.js` (posts; `src/posts.js` → `src/figs/solar*.js`, `src/figs/wind*.js`, `src/figs/xfmr*.js`, `src/figs/txl*.js`). The build injects the series nav (current page marked) before `<main>`, prev/next links at the bottom of each article, and an `id="fig-<name>"` on every figure that lacks one.
- **Post sources:** `src/posts/<file>.html`. Cross-links use `class="xref"`; deep-dive boxes use `<aside class="deepdive d-…">`.
- **Link check:** `pnpm run links` checks every internal `href`/`src` (file exists, `#anchor` exists, ids unique, no root-absolute paths). All links are relative, so `dist/` works from `file://` and from any static host.
- **Audit:** `node scripts/audit.mjs [widths] --page=solar-pv.html [--stress]` → `screenshots/audit-solar-pv[-stress].txt`.
