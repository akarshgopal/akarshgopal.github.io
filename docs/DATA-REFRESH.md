# Data refresh: what each figure's data is, how old it is, and how to update it (9 Nov 2026)

Every figure value in the electricity series comes from a named source or from the series' own arithmetic. This
page lists each dataset, the figures that use it, how current it is, when its source usually publishes again, and
how to rebuild it. Release timings are **typical**: check the publisher before planning around them.

## Before you start: most raw files are not in this repo

The generator scripts (`scripts/make_*.py`) were written against raw downloads kept in `/workspace/research/…`, a
folder that never came into this repo. Only `scripts/data/` (10 CSVs, the historical US and German accounts) is
here. Refreshing almost any dataset therefore means downloading the source again from the address below, and
passing the file path to the script; most scripts already take one. Where a script hard-codes a `/workspace` path,
pass the new path or edit the constant.

## The routine for any refresh

1. Download the new release, and note the date and (where the script records one) the sha256.
2. Regenerate with `python3 -P scripts/make_<x>.py <raw file>`. This writes `src/lib/<x>data.js`. Check that the
   file header now carries the new date.
3. Run `git diff --stat src/lib/` and skim the diff for revisions to *old* years, not just the new year. Sources
   revise back-data (Ember and the EIA often do).
4. **Re-read the prose.** The figures update themselves, but the text does not. Each page quotes numbers from its
   figures: the "In brief" box, captions, the figure notes and the body text. Search the page for the old values.
   The column "Text to re-check" below lists the main ones.
5. Build and check: `node build.mjs`, the step check, `scripts/audit-local.mjs 1280,390`, and
   `scripts/linkcheck.mjs`. Then update the note's "fetched" date on the page and deploy as in `HANDOVER.md` §3.
